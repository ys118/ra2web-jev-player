## 边界

- 玩家查询只投影公开信息、当前视野与己方状态，返回数据副本。
- 基础动作复用正常锁步命令。引擎内的行动合法性、地形/武器等查询可保留；候选排序、搜索、路线策略、部队分组和模型选择属于用户侧。
- 不修改共享 AI API、内置机器人、战斗数值、同步协议或兄弟仓库。
- 公开 TypeScript 合约必须精确，随 werhd 自身构建发布，不依赖 game-api 包或机器人重新构建。

### 玩家 API 失效对象与副本

- 底层 `World.getObjectById` 对已删除 id 抛错。玩家适配层现在先验证整数 id 与世界中是否存在，再读取物体；`unit` 对无效、已消失、已摧毁或不可观察单位返回 `undefined`，`weaponVs` 返回 `undefined`，`inRange` 返回 `false`，`order` 拒绝失效目标并过滤失效己方单位，`select` 跳过失效 id。
- 修正 `map.size()` 返回内部尺寸对象的问题，改为数据副本。真实引擎测试会修改返回值并核对地图尺寸与模拟哈希，防止用户脚本意外改变 AI 的地图扫描。
- 上述修复仅在 `PlayerConsoleApi`，没有改变 `World` / `Game` 的查找语义，也没有修改共享 `GameApi`、机器人、指令执行器或规则数值。
- 运行时桩改为与真实引擎一致：不存在的 id 抛错。回归覆盖无效数值、失效攻击者/目标、选择与批量指令；真实模拟覆盖卖掉建筑后再次查询和下令。
